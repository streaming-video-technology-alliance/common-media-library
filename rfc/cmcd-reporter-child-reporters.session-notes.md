## Outstanding work, in order

1. **Prerequisite-fixes PR: open as #416, review round 1 absorbed.** Round 1 (2026-08-11, 4 threads from Casey, all replied and resolved) found stale-response relabeling, cross-session batch retries, an msd RFC 8941 range gap, and single-config 410 disposal for shared URLs. Outcome is structural, designed in `plans/cmcd-session-fixes/session-state.md` (approved before implementation): session-scoped state lives in per-session objects retained under a new public `CmcdReporterConfig.sessionRetention` (default 3, floored, min 1; the PR's only API addition). Key semantics: `recordResponseReceived()` resolves its session via stored request `sid`, then per-call `data.sid`, then current; unknown or evicted keys drop the event; the data store carries across resets by shallow copy; a reused `sid` replaces its archived namesake; archived sessions drain without waiting for `batchSize`; timers are reporter-level keyed by target config; `sessionEpoch` and the planned generation counter were deleted as unnecessary. The feature PR should build on the session object (children share `root.session`). Original issue set: filed 2026-08-11: #408 (reserved `sid`/`msd` overridable per call and via transforms, plus the `update({ sid: undefined })` poisoning), #409 (`msd` validation, session-reset clearing, gate-before-filter), #410 (410 disposal outlives the session). Plan and design record: `plans/cmcd-session-fixes/` on that branch. Fix shape that the feature PR builds on: `sid` is now a private reporter field stamped pre-transform (visibility) and post-transform (integrity) in both modes; a report's `msd` is exclusively gate-produced, and the gate is consumed only when the output retains `msd` (event mode checks the target's `enabledKeys` at enqueue; request mode checks the prepared output); `resetSession()` clears `msd`/`msdSent`, bumps a `sessionEpoch`, and restores 410-disposed targets (re-arming intervals only while `started`); a stale-epoch 410 is ignored. ## Key verified facts (do not re-derive)

- **Spec (CTA-5004-B)**: contains no duplicate-suppression clause for state events; state-change triggers are player-scoped; `bg` is defined over "all players in a session"; `msd` is "Integer milliseconds" and once per Session ID per active mode; 410 suppression is scoped to "the remainder of the current session"; no delivery-deadline language exists anywhere (deferred delivery twice endorsed); mixed v1 request mode with v2 event mode is recommended; per-target versions are live library behavior today; the only multi-player example (8.1.7) shows interleaved per-player lines under one `sid` disambiguated by `cid`/`nr`; the only `t` example (8.2.2) is a single stream "for an active player".
- **hls.js (master, verified in source)**: `interstitialAppendInPlace` transfers the media element and MediaSource/SourceBuffers to the child `Hls` instance; the primary's `CMCDController` detaches (media nulled, buffer queries `NaN`); `CMCDController.destroy()` unconditionally calls `reporter.stop(true)` per asset teardown, plus a reset path.
- **TypeScript (repo's 5.8.2, strict, no `exactOptionalPropertyTypes`)**: `never` locks reject literal, widened, and spread-built configs; `Omit` alone only guards literals; locks render as `undefined` in tooltips/errors (TSDoc carries the reason); a `Pick` including a factory returning the class is nominal across package copies; a recursively structural alias is not.
