@svta/cml-iso-8601 changelog ​

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

Unreleased ​

1.0.3 - 2026-10-26 ​

Changed ​

  • The README now has a When to use section. The section names the tasks that the package covers and the entry point of each task.

Fixed ​

  • decodeIso8601Duration gives NaN for a malformed duration. Before, P1H gave 3600 and PTH1M gave 60. A time designator needs the T, and every designator needs a number.

1.0.2 - 2026-07-21 ​

Changed ​

  • Promote the package API from @beta to @public: decodeIso8601Duration and encodeIso8601Duration are now documented as stable (#288)

1.0.1 - 2025-12-22 ​

Fixed ​

  • Use fixed version numbers for all CML peer dependencies (#277)

1.0.0 - 2025-10-24 ​

Changed ​

  • Remove CommonJS exports (#192)
  • Convert to mono-repo (#238)
  • Produce single bundled export for each package (#260)
