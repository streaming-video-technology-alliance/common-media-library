Common Media LibraryShared libraries for web video players

TypeScript implementations of CMCD, CMSD, ISO BMFF, captions, DRM, C2PA, and more. Maintained by the Streaming Video Technology Alliance.

Browse packages
GitHub

  • Spec-accurate

    Each package implements one specification. No invented extensions.

  • Tree-shakeable

    Import one function and ship only that function.

  • Typed

    Union and literal types guide autocomplete. Incorrect usage fails at compile time.

  • Peer dependencies stay inside CML

    No framework, no runtime, no polyfills.
