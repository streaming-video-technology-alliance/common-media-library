## Releases

Packages released since the 2026-08-11 call:

**@svta/cml-iso-bmff v1.0.5** (2026-08-11)
- Fixed `writeTerminatedString` so empty strings get a null terminator. `writeEmsg` output with an empty `value` or `schemeIdUri` no longer misaligns the fields that follow ([#411](https://github.com/streaming-video-technology-alliance/common-media-library/issues/411), [#412](https://github.com/streaming-video-technology-alliance/common-media-library/pull/412), release [#413](https://github.com/streaming-video-technology-alliance/common-media-library/pull/413))

**@svta/cml-drm v1.1.9** and **@svta/cml-c2pa v1.1.2** (2026-08-11)
- Dependency update to `@svta/cml-iso-bmff` 1.0.5 ([#413](https://github.com/streaming-video-technology-alliance/common-media-library/pull/413))

**@svta/cml-608 v1.1.0** (2026-08-13)
- Added `extractCta608DataFromAv1Sample` to extract CTA-608 captions from AV1 `metadata_itu_t_t35` OBUs ([#407](https://github.com/streaming-video-technology-alliance/common-media-library/pull/407), release [#418](https://github.com/streaming-video-technology-alliance/common-media-library/pull/418))
- The `cc_data()` parser is shared by the SEI and OBU paths and is bounded by the enclosing structure
- Fixed a wrong `cc_count` reading caption pairs from the next SEI message, and a `RangeError` on an A/53 payload with no `cc_data()`

**@svta/cml-cmcd v2.6.0** (2026-09-04)
- Added `CmcdReporterConfig.sessionRetention` and `CMCD_REQUEST_PROVENANCE`, so a request that completes after a `sid` change reports under the session that issued it. Implements the session retention RFC ([#416](https://github.com/streaming-video-technology-alliance/common-media-library/pull/416), RFC [#417](https://github.com/streaming-video-technology-alliance/common-media-library/pull/417), [#421](https://github.com/streaming-video-technology-alliance/common-media-library/pull/421))
- Added `CmcdDecodeOptions.useSymbol` so decoded RFC 8941 tokens keep their wire type and `encodeCmcd(decodeCmcd(s))` round-trips (related to [#419](https://github.com/streaming-video-technology-alliance/common-media-library/issues/419))
- Fixed `decodeCmcd` dropping RFC 8941 parameters on dictionary members and inner lists
- Fixed session-owned `sid` and `msd` being overridable by per-call data or transforms ([#408](https://github.com/streaming-video-technology-alliance/common-media-library/issues/408))
- Fixed the `msd` lifecycle: `0` accepted, fractional values rounded, invalid values rejected, gate re-armed on `sid` change ([#409](https://github.com/streaming-video-technology-alliance/common-media-library/issues/409))
- Fixed HTTP 410 event target disposal so it is scoped to the session that received the 410 ([#410](https://github.com/streaming-video-technology-alliance/common-media-library/issues/410))
- Event reports are encoded when queued, so an un-encodable report throws at the call site instead of blocking the batch forever
- Corrected the `CmcdEncodeOptions.version` default in the docs to `CMCD_V2` ([#420](https://github.com/streaming-video-technology-alliance/common-media-library/pull/420))
- README and guides rewritten under the new writing style rules ([#437](https://github.com/streaming-video-technology-alliance/common-media-library/pull/437))

**@svta/cml-xml v1.2.0** (2026-09-04)
- `parseXml` rewritten as a flat, non-recursive scanner. Parsing is 20 to 40 percent faster on dense `SegmentTimeline` manifests and nesting depth is no longer limited by the call stack ([#424](https://github.com/streaming-video-technology-alliance/common-media-library/issues/424), [#426](https://github.com/streaming-video-technology-alliance/common-media-library/pull/426), [#432](https://github.com/streaming-video-technology-alliance/common-media-library/pull/432))
- Fixed `parseXml` hanging on an attribute with no quoted value, on input truncated inside the XML declaration, and on input truncated inside a close tag ([#425](https://github.com/streaming-video-technology-alliance/common-media-library/pull/425), [#430](https://github.com/streaming-video-technology-alliance/common-media-library/pull/430))
- `parseXml` now throws `Unexpected close tag` on a close tag whose name only starts with the open tag name, and on a document-level close tag ([#430](https://github.com/streaming-video-technology-alliance/common-media-library/pull/430))
- Changed: a quoted attribute value with no `=` now throws instead of parsing leniently
- README example calls `parseXml` instead of the removed `decodeXml` ([#441](https://github.com/streaming-video-technology-alliance/common-media-library/pull/441))

**@svta/cml-request v1.0.16** and **@svta/cml-drm v1.1.10** (2026-09-04)
- Dependency updates to `@svta/cml-cmcd` 2.6.0 and `@svta/cml-xml` 1.2.0. A usage example replaces the empty README code block ([#441](https://github.com/streaming-video-technology-alliance/common-media-library/pull/441), release [#444](https://github.com/streaming-video-technology-alliance/common-media-library/pull/444))
