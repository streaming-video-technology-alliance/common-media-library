Defined in: segment/validateC2paSegment.ts:51

Validates a C2PA live stream segment using the VSI/EMSG method (§19.7.3).

Extracts the EMSG box, decodes the COSE_Sign1 and VSI map, matches the session key by kid, then performs all cryptographic checks: signature verification, BMFF content hash, sequence number floor, and key validity.

Returns null if the segment does not contain a C2PA EMSG box.

A segment whose signature, content hash, or key validity does not verify returns the received sequenceState unchanged.

A duplicate, out-of-order, or below-minimum sequenceNumber fails with livevideo.segment.invalid. A gap in the sequence numbers does not fail the segment. result.sequenceResult reports the gap with its missing range.
