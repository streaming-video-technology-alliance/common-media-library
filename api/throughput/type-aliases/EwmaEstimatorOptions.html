Properties ​

defaultEstimate? ​

ts
defaultEstimate?: number;

Defined in: EwmaEstimatorOptions.ts:13

The estimate, in bits per second, that getEstimate returns before the first sample. getEstimate also returns this value while the sampled bytes are below minTotalBytes.

Default Value ​

NaN

fastHalfLife ​

ts
fastHalfLife: number;

Defined in: EwmaEstimatorOptions.ts:49

The half-life of the fast moving average, in seconds. Samples from the last fastHalfLife seconds have half of the weight in the estimate. shaka-player uses 2.

minBodySize? ​

ts
minBodySize?: number;

Defined in: EwmaEstimatorOptions.ts:32

The smallest encodedBodySize, in bytes, that counts as a sample. A sample with an encodedBodySize of 0 never counts. The estimator ignores smaller responses, because their transfer is too short to measure. shaka-player uses 16000.

Default Value ​

0

minTotalBytes? ​

ts
minTotalBytes?: number;

Defined in: EwmaEstimatorOptions.ts:22

The number of bytes to sample before getEstimate returns a measured estimate. Below this total, getEstimate returns defaultEstimate. shaka-player uses 128000.

Default Value ​

0

minTransferDuration? ​

ts
minTransferDuration?: number;

Defined in: EwmaEstimatorOptions.ts:42

The shortest transfer, in milliseconds, that counts as a sample. The transfer runs from responseStart to the end of the response when the sample has responseStart, and over duration otherwise. A body that arrives within a few milliseconds of its headers came from a cache, and its rate says nothing about the network. shaka-player uses 5 as cacheLoadThreshold.

Default Value ​

0

slowHalfLife ​

ts
slowHalfLife: number;

Defined in: EwmaEstimatorOptions.ts:56

The half-life of the slow moving average, in seconds. Samples from the last slowHalfLife seconds have half of the weight in the estimate. shaka-player uses 5.
